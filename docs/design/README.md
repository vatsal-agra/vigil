# Design — Review 2

Everything the Review 2 software design refers to. The write-up itself is
[`Vigil_Software_Design_Document.pdf`](Vigil_Software_Design_Document.pdf).

## Diagrams (`diagrams/`)

Each diagram is an editable draw.io file with a PNG export beside it. Open a `.drawio` at
[app.diagrams.net](https://app.diagrams.net) via **File → Open from → Device**.

| File | Shows |
|---|---|
| `01-architecture` | System architecture: client → edge → frontend → API → cache / database, plus the probe worker |
| `02-module-layers` | Every source file, the layer it belongs to, and its downward-only dependencies |
| `03-data-model` | The four PostgreSQL tables and their relationships |
| `04-monitor-state-machine` | Monitor status transitions and the incident lifecycle implemented in `app/probe.py` |

`01-architecture.drawio` is copied from [`infra/architecture.drawio`](../../infra/architecture.drawio). The other three are
generated by [`scripts/make_design_diagrams.py`](../../scripts/make_design_diagrams.py). The PNGs are rendered from the
`.drawio` files by [`scripts/export_diagrams.py`](../../scripts/export_diagrams.py) using the official diagrams.net
viewer, so each image matches its source.

```bash
python scripts/make_design_diagrams.py
python scripts/export_diagrams.py
```
